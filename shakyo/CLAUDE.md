# CLAUDE.md — うさうさ写経道場

うさうさ研修工房の、タイピング（写経）ゲーム。お手本の文を見ながら、同じ文を打って写す。
1ファイルの HTML。オフラインで動く。外部の読みこみはない。

- 版数：`APP.version`、刻印：`APP.grade`（どちらも `src/shakyo.html` の中で1か所だけ）
- 今の版：PRO v1.2.0
- ライセンス：CC BY-NC 4.0。商用利用は個別に許可を出す
- 合言葉：面白きこともなき世を面白く

## フォルダ

```
├─ dist/

└─ test/
   ├─ run.js            jsdom の回帰テスト（114件）
   └─ e2e.py            Playwright。4つの画面幅 × 3つの見た目、暗い画面、本物のダウンロード、キーボードだけの操作
```

## 作り直し・直すときの手順

```bash
./build.sh
JSDOM=<jsdom のパス> node test/run.js     # 0 fail になるまで出さない
python3 test/e2e.py <画像の出力先>        # errors: none を確認し、390px と 1280px の画像を目で見る
```

本体を直したら、配布用 HTML とアーティファクトの両方を出し直す。アーティファクトの機能は `mcp`（Notion の notion-fetch）と `downloads` の2つ。出し直すときは両方を書く。

## 前の作品から受けついだもの

参考にしたのは「LPIC クイズ RPG（ドット風）」。受けついだのは仕組みだけ。

| クイズ RPG | 写経道場 |
|---|---|
| HUD（LEVEL・EXP・SCORE・COMBO・TIME） | 段位 LV・経験値の棒・SCORE・COMBO・TIME（秒）・ミス・正確さ |
| Web Audio の効果音 | ベルのボタンで鳴らす（最初は音なし） |
| 正解の花吹雪 | 写し終えたときに花びら |
| 問題エディタと一括取り込み | 「自分の文章を入れる」（貼り付け・メモ帳・Notion） |
| 空・雲・レンガの地面 | 見た目「ドット」のときだけ |

**任天堂のキャラクター・名前・キノコ・コイン・土管は使わない。** 絵は全部オリジナル。タイトルや文書に「マリオ」と書かない。

## 画面の流れ（初心者を迷わせない）

```
準備中 ──「開始 ▶」または入力欄をクリック──▶ 写しています ──最後の字まで打つ──▶ おしまい（結果）
                                               └──「おしまい ■」で途中終了──▶ おしまい（途中の結果）
Esc：写している間はやり直し／結果の画面ではもう一度
```

- はじめての方への案内（4つの手順）。「わかった」で閉じると覚える。「遊び方を見る」でまた出る
- 棚は 入門 → 初段 → 二段 → 三段 の順。最初の課題は入門
- 次に打つ字と「n / 全部 字」を出す。違うときは「4字目がちがいます。お手本は「、」、打った字は「。」です」と具体的に出す
- 多く打ちすぎたら「2字多く打っています」と出す
- 時計を使う／使わない、全角・半角を気にしない（初期は気にしない）。写している間は変えられない
- 🔔 ベル：効果音のオン／オフ。初期は音なし。オンにすると鈴の音で知らせる
- 💻 📱：パソコン画面とスマホ画面を手で切りかえる。押す前は画面の幅（820px 以下はスマホ）で決める
  - パソコン：棚と机の2列
  - スマホ：机だけの1列。課題は机の上の選択欄でえらぶ。HUD は2段に詰める
- 見た目は3つ（`body[data-skin]`）：classic クラシック（原稿用紙）／dot ドット／night 夜の書斎
- 貼り付け・ドロップは止める（写経なので）。Enter で改行させない
- ダイアログはフォーカスを中に閉じ込め、閉じると元の場所へ戻す
- お手本は原稿用紙のマスで見せ、読み上げ用に同じ文を隠し文字で持つ

## 練習のしかたと長文

| しかた | 量 | 中身 |
|---|---|---|
| 1題 | — | えらんだ課題を1つ |
| 文の数 | 3・5・10・20・50 文 | えらんだ課題から、同じ作品の続きの文を順に。最後まで行ったら作品の最初へ戻る |
| 字数 | 100・200・400・800・1600 字 | 同じく続けて、その字数に届く文まで（文の途中では切らない） |
| 時間 | 1・3・5・10・15 分 | 時間になるまでお手本が続く（足りなくなったら足す）。時計は必ず使う。HUD は「のこり 2:30」 |

- 長い文は `Logic.buildPages` で文に分け、1ページ80字（`APP.chunk`）に詰める。1ページ写すと自動で次のページへ（ページの音つき）
- 1つの文が80字をこえるときは80字で切る
- 「作品」＝取り込んだまとまり（貼り付けの名前・ファイル名・Notion のページ名）。棚は作品ごとにたたむ。続きの文は同じ作品の中だけで取る
- 自分の文章は2000題（約16万字）まで（`APP.maxMine`）
- 最高記録は「1題」で最後まで写したときだけ。ほかのしかたは記録（履歴）だけに残す
- 写している間は、練習のしかた・量・時計・全角半角の設定は変えられない

## 採点（ロジック層 `Logic`）

DOM を触らない純粋関数。テストはここを叩く。

| 関数 | すること |
|---|---|
| `same(a, b, loose)` | loose なら NFKC でそろえて比べる（！と!、全角と半角の空白） |
| `judge(target, typed, loose)` | 1字ずつ ok・ng・todo。多すぎた字数 `over`。`done` は全字一致 |
| `step(state, target, typed, loose)` | 前回との差分だけ採点。1字 10点＋コンボ（50まで）。同じ位置で二度は加点しない |
| `cpm(字数, ms)` | 1分あたりの字数。時間は最低1秒で数える |
| `rank(正確さ, cpm, timer)` | 時計あり：秀 98%以上かつ100字/分以上、優 95%以上かつ60字/分以上、良 90%以上、可。時計なし：正確さだけ |
| `clearBonus` | 字数 × 20 × 正確さ × 段位の倍率（秀3・優2・良1.5・可1）。途中でおしまいは0 |
| `addExp` | 正しく打てた字数が経験値。次の段位まで `40 + LV×20` |

段位のしきい値は**この道場の決まり**で、研究や統計の数字ではない。画面にもそう書いてある。

## 記録と書き出し

- 写し終える・時間になる・「おしまい」を押す、のたびに日付（YYYY-MM-DD）と時刻つきで1件残す。結果は「完了／時間まで／途中でおしまい」。最大2000件
- 結果の画面に「2026年10月31日（土） 17:48」の形で日付を出す
- 「今日の記録を保存（CSV）」→ `shakyo-kiroku_YYYY-MM-DD.csv`。「すべて」→ `shakyo-kiroku_all_YYYY-MM-DD.csv`
- CSV は UTF-8＋BOM（Excel で文字化けしない）、CRLF。`= + - @ タブ` で始まる値は先頭に `'` をつける（数式の実行を防ぐ）
- 列：日付・時刻・課題・練習のしかた・結果・ページ数・お手本の字数・正しく打てた字・時計・秒・1分あたりの字数・正確さ(%)・ミス・最大コンボ・スコア・段位
- 保存の仕組み：claude.ai の中では `downloads` 機能（保存の確認が出る）。1ファイル版ではブラウザの保存。どちらも無理なら、うそで「保存しました」と出さず、「表をコピー」へ案内する
- 「表をコピー」はタブ区切り。スプレッドシートにそのまま貼れる

## 自分の文章を入れる（メモ帳・Notion）

| 入れ方 | 中身 |
|---|---|
| 貼り付け | メモ帳・Notion・Word の文をコピーして貼る。空行で段落に分ける |
| ファイル | メモ帳の `.txt`（UTF-8・ANSI〈Shift_JIS〉・Unicode〈UTF-16〉を見分ける）、Notion の書き出し `.md`・`.csv` |
| Notion から直接 | アーティファクトの `mcp` 機能で、見る人の Notion コネクタの `notion-fetch` を呼ぶ。読むだけ。戻り値は `{title, text}`（text の中の `<content>` を本文にする） |

- 文字コード：BOM を見る → UTF-8 として厳しく読む → だめなら Shift_JIS。UTF-8 以外で読んだときは画面で知らせる
- `.md`：最初の `#` 見出しが題名。Notion の書き出しのときだけ先頭の「属性: 値」行を外す（貼り付けの1行目は落とさない）
- `.csv`：「タイトル／名前／Name」の列が名前、「本文／内容／Text」の列が本文
- 英文の改行は空白にしてつなぐ。日本語はそのままつなぐ
- 自分の文章は2000題まで（`APP.maxMine`）。こえた分は入れずに知らせる。保存の容量をこえたら入れずに知らせる
- 消すのは作品ごと。「消す」→「本当に消す」の2回押し
- 保存は見る人のブラウザの中だけ（localStorage `usausa-shakyo-v1`）。壊れた保存・古い形は `Logic.sanitize` で整えて開く。読めなかったときは画面の下で知らせる

## 守ること

- 外部の読みこみを入れない（テストで検査）
- 版数・刻印を手書きで増やさない。`APP` だけ変える（テストで検査）
- 見本の本文を記憶で書かない。必ず青空文庫で確かめ、確認日を書きかえる
- 他人の作品・キャラクターを絵や名前で入れない
- 機能が使えないときは黙って無効にしない。理由と代わりを画面に出す
