##  読者限定特典：AI駆動開発（ADD）拡張アセットパック（skills/ / 各フォルダ）

AI駆動開発の品質と効率を最大化するための**カスタムエージェント設定ファイル群**を同梱しています。
AIを指示待ちのアシスタントから、「品質を自律的に担保するチームメンバー」へと引き上げるための実践的な仕組みです。

### 1. `spec-docs.skill` （仕様駆動開発支援）
* **役割**: 実装前に「仕様定義」のプロセスを強制し、AIのハルシネーションと手戻りを防ぎます。
* **内包ファイル**: `SKILL.md`（メイン指示書）、`references/doc-format.md`（ルールブック）、`scripts/new_spec.py`（テンプレート自動生成）、`scripts/check_spec.py`（仕様事前検証スクリプト）。

### 2. `feature-bugfix-workflow` （機能開発・バグ修正ワークフロー）
* **役割**: 新機能追加やバグ修正のサイクルを自律化し、現在の進捗を `CLAUDE.md` へ動的に同期させます。
* **主要ファイル**: `SKILL.md`（メイン指示書）、`references/feature-template.md` / `bugfix-template.md`（設計テンプレート）、`references/claude-md-snippet.md`（動的更新スニペット）、`references/standards-and-papers.md`（ナレッジベース）。
* *※ルート直下の `feature-bugfix-workflow/` フォルダに、解凍されたマスターデータも格納されています。*

### 3. `engineering-method.skill` （アーキテクチャ・品質監査）
* **役割**: プロジェクトが定義された開発標準やディレクトリ構造に準拠しているかをAIがセルフチェックします。
* **内包ファイル**: `SKILL.md`（メイン指示書）、`references/method.md`（設計思想サブドキュメント）、`scripts/audit_project.py`（技術負債検知スクリプト）。
